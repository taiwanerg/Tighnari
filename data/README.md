# Local data / 本機資料

Downloaded station data stays on this computer. Do not commit waveform archives or credentials.
The active database, models, report images, and waveform files are in `runtime/`.
Retention is set by `TIGHNARI_WAVEFORM_RETENTION_HOURS` in `.env` (see `.env.example`).

下載的測站資料保留在本機。請勿提交波形封存或憑證。
目前資料庫、模型、定位圖及波形檔案存放在 `runtime/`。
保存期限由 `.env` 的 `TIGHNARI_WAVEFORM_RETENTION_HOURS` 設定（見 `.env.example`）。
