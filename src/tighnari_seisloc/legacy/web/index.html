ANALYSIS PIPELINE

先確認訊號，再推估震源。

  1. 檢查資料

    拒絕過期、重複、亂序與平線波形。缺口後重新暖機。

  2. 辨識到時

    因果帶通、STA/LTA、持續能量與訊噪比檢查，再用 AIC 修正到時。

  3. 多站確認

    至少四個獨立站址、附近測站參與率達 40%，並檢查傳播時間。

  4. 穩健定位

    多深度起點、軟化殘差損失與離群值剔除。方位涵蓋不足時標示待確認。
